# Obstacle Dodge 🏃‍♂️💨

A 3D obstacle avoidance game built in **Unity 6**. Control your character to dodge moving and static obstacles, survive as long as possible, and reach the goal!

---

## 🎮 Gameplay & Features

- **3D Character Controls**: Move and navigate around challenging hazards.
- **Dynamic Obstacles**: Avoid collisions with varied obstacles.
- **Universal Render Pipeline (URP)**: Optimized, modern visuals and lighting.

---

## 🛠️ Requirements & Tech Stack

- **Game Engine**: [Unity 6 (6000.4.6f1)](https://unity.com/releases/editor/whats-new/6000.4.6)
- **Render Pipeline**: Universal Render Pipeline (URP)
- **Language**: C#
- **Input System**: Unity New Input System

---

## 🚀 Getting Started

### 1. Clone the Repository
```bash
git clone https://github.com/Dimalex7/Obstacle-Dodge.git
```

### 2. Open with Unity Hub
1. Open **Unity Hub**.
2. Click **Add** -> **Add project from disk**.
3. Select the `Obstacle Dodge` folder.
4. Make sure to open using **Unity 6 (6000.4.6f1)** or compatible version.

### 3. Play the Game
1. In the Project window, navigate to `Assets/Scenes/`.
2. Open the main scene (e.g. `SampleScene.unity`).
3. Press the **Play** button at the top of the Unity Editor.
